## Code corrections proposed

1. Avoid concurrent setup loops during WebView2 initialization / SSO `LoginRequired`; one setup waits across manual login.
2. If a legitimate WMS printer modal is already open, adopt it without sending a second `ACCOUNT_OPEN`. Delay opening account menu while an unrelated WMS modal blocks interaction.
3. Give the autocomplete real DOM focus before synthetic click and dispatch its normal `input` notification; recognize scrollable Angular Material autocomplete panels and record options.
4. Retain explicit operator choice and readback. A changed printer uses `Xác nhận` then reopen-and-verify, and a current/unchanged printer uses `Đóng`. Fail closed if any choice or dialog cannot be confirmed; SO input stays disabled.
5. Extend mocked regression for focus-only autocomplete and an already-open printer modal, in addition to two WMS routes and changed/unchanged printer behavior.
